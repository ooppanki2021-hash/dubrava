## Нельзя писать нигде — ни на сайте, ни на упаковке, ни в карточках

| Запрещено | Почему |
|---|---|
| «Лечит», «убивает», «уничтожает», «100%», «навсегда» | Это заявления о медицинском действии. Косметика и бытовая химия их делать не вправе |
| «Дуб лучше хурмы», «танинов в 3-4 раза больше» | Сравнение без лабораторного подтверждения = недостоверная реклама, ст. 5 ФЗ «О рекламе». **Уже удалялось с сайта 15.09** |
| «У 2/3 людей после 40» | Некорректная интерпретация исследования |
| **Название Letocosmetics — в любом виде** | Решение автора 17.09 и 19.09. Категорически не упоминать нигде. Формулировка: «5 лет на производстве натуральной косметики» |
| **Утверждать, что кора сейчас собирается вручную** | Запрещено. Ручной сбор в Осетии — прошлый экспедиционный опыт изучения свойств сырья. Сейчас — КОНТРАКТНОЕ ПРОИЗВОДСТВО: закупается сухой стандартизированный экстракт коры дуба (российские танины). Проценты танинов (8–20% и т.п.) на сайте не указывать |
| **«Хобби» про проект** | Автор отвергла 17.09. Происхождение: японское мыло на хурме → исследование → «могу сделать лучше» |
| **Дисклеймерный тон на `/o-proekte/`** | Разделы «чего продукт не делает», «тест ещё не проведён», «знак не зарегистрирован» — удалить. Автор: «никакого доверия не вызывает» |
| «n=22» | Ссылка на выборку, которой нет в открытом доступе |
| Любые заявления об эффективности против 2-ноненаля | **До проведения headspace-теста.** Механизм для дуба лабораторно не подтверждён |

# 3. ОТКЛОНЁННЫЕ РЕШЕНИЯ — не предлагать заново

## Дизайн

| Отклонено | Что вместо |
|---|---|
| Плавный градиент, перелив, голограмма, перламутр | Плоские сегменты с жёсткими стыками |
| Вариант v6 радужной плашки | Выбран **v5** — сегменты под всем текстом |
| Полная яркость радуги | Яркость снижена вдвое → финал **v8** |
| «40+» золотом | Только **охра**, как у слова «СТОП» |
| «40+» в две строки | Только в одну строку с «ДУБРАВА» |
| Радужный код на средствах для тела | Только линия стирки |
| Логотип на прозрачном фоне | Не читается. Всегда на кремовом |
| Мелкий текстовый блок по центру корешка | Названо «уродством». Текст заполняет корешок целиком |

## Инструменты

| Не работает | Подтверждено |
|---|---|
| **`generate_image` для панелей с русским текстом** | 9 итераций. Перевирает слова: «силые», «катриат каробонат», «дӯшка», «изготовленилиеры». Дублирует пункты списка. Правка поверх не помогает |
| **SVG + ImageMagick `convert`** | Теряет `stroke` рамок, не поддерживает inline-`tspan` со смешанным кеглем, подставляет serif вместо sans |
| `rsvg-convert`, `inkscape`, `cairosvg` | В системе отсутствуют |

**Рабочий способ для макетов с текстом — только Python + Pillow.** Скрипты в `04_упаковка/скрипты_генерации/`.

**Про шрифты:** кириллических шрифтов кроме DejaVu нет. Узкий гротеск оригинала не повторить — дизайнер заменит шрифт в печатном исходнике.

# 5. ПОРЯДОК РАБОТЫ

## Что Инна просила явно

1. **Резюме проекта — один файл навсегда.** Промежуточные и устаревшие удалять, чтобы не тормозило.
2. **Сначала обсудить, потом делать.** Показать варианты, дать выбрать.
3. **Спины упаковки** — делать по исходнику мыла, менять только строку применения и профильные слова.
4. **Логотип** брать с лицевой стороны коробки, менять **на всех спинах сразу**, чистая копия без «порванности».
5. Файлы к заливке отдавать **архивом с сохранением структуры папок** — Инна заливает через веб-интерфейс GitHub.

## Правило масштабирования

**Новый SKU только после окупаемости предыдущего.** Не печатать пять видов упаковки сразу.

## Правило текстов

**Страница не публикуется, пока не закрыты все пять букв AUDIO.** Объём наращивать только за счёт фактуры, которой нет у конкурентов. 450 слов по делу лучше 900 с водой.
