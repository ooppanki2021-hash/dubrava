# Решение 1. Стартовать порошком, а не мылом

**Когда:** при составлении сметы.

**Логика:** мыл на маркетплейсах десятки тысяч — новый бренд утонет в выдаче. Порошок против запаха — пустая ниша. Плюс порошок это расходник: кончается, покупают снова. Мыло тоже расходник, но конкуренция несопоставима.

**Следствие:** первый SKU — порошок для цветного белья. Бюджет 350–450 тыс ₽.

# Решение 4. Рендер макетов кодом, не нейросетью

**Когда:** на этапе упаковки.

**Почему:** 9 итераций `generate_image` показали, что модель перевирает русский текст («силые», «катриат каробонат», «изготовленилиеры») и дублирует пункты списков. Правка поверх готового изображения дубли не устраняет.

**Решение:** макеты с текстом рендерятся Python + Pillow. Скрипты сохранены.

**Что пробовали и отвергли:** SVG + ImageMagick — теряет обводку рамок, ломает смешанный кегль внутри строки, подставляет serif.

# Решение 8. Измеренное число вместо округлённого

**Когда:** 17 сентября.

**Что было:** на четырёх страницах стояло «полиэстер держит жирные альдегиды в 2-3 раза сильнее хлопка», а источником значилось «cir.nii» — голый текст ссылки.

**Разбор:** ссылка вела на настоящую статью (Munk et al. 2000, *J Surfact Deterg*), но **числа «в 2-3 раза» в ней нет**. Она подтверждает только направление: из хлопка запах вымывается, на полиэстере держится.

**Решение:** вместо округлённого числа поставить измеренное и закрыть его ссылкой на DOI. Из Abdul-Bari et al. 2020 (*Text Res J*): обычная стирка удаляет **94,2 %** 2-ноненаля из хлопка и только **59,0 %** из полиэстера. Цифру «в 4–8,5 раза больше в headspace» **не использовали** — это лабораторный замер, его легко оспорить, а наша же красная линия запрещает цифры без первоисточника.

**Побочный эффект:** эти 94/59 работают на продукт лучше, чем «в 2-3 раза», — они прямо объясняют, зачем стирать при 60 °C.

# Решение 9. Letocosmetics — только как место прошлой работы

**Когда:** 17 сентября, найдено при сверке архива с сайтом.

**Проблема:** на двух страницах сайт утверждал то, чего нет: «Владикавказ, **лаборатория Letocosmetics**», «Кора + травы **для Letocosmetics**», «реальное **производство Letocosmetics с 2019 года**», «**Мы в Letocosmetics сделали** мыло». Инна там работала пять лет, но компания не её, и продукт делается на контрактном производстве.

**Как это всплыло:** 15.09 страницу правили дважды параллельно — одна версия убрала сравнение про танины и ушла на сайт, другая убрала Letocosmetics и осталась в архиве и не была залита. Сверка архива с живым сайтом показала, что **ни одна из версий не была полной**. 17.09 обе правки объединены.

**Правило:** Letocosmetics можно упоминать только как место прошлой работы («5 лет в Letocosmetics»). Никогда — как своё производство, свою лабораторию или автора продукта.

**Вывод для нового ассистента:** архив и сайт могут разойтись молча. Перед правками сверять содержимое, а не даты.

# Решение 10. Заливка на сайт — через API, не через телефон

**Когда:** 17 сентября, после двух аварий подряд.

**Что случилось:**
1. Телефонное приложение GitHub **не сохраняет папку**: тащишь папку `karta-osetii`, а оно вынимает `index.html` и кладёт в текущее место. Так главная страница сайта была перезаписана страницей карты Осетии.
2. До этого файл создался пустым — 1 байт, один перевод строки. Страница отдавала 200 и пустоту, что для поиска хуже, чем 404.

**Решение:** заливку делает ассистент через GitHub API по fine-grained токену (Contents: Read and write только на `zapahstarosti`) — один атомарный коммит, сразу с проверкой. Вручную — только с компьютера, по ссылке `…/upload/main/<папка>`, где путь задан в адресе.

**Обязательная проверка после любой заливки:**
```bash
curl -s https://zapahstarosti.ru/ | grep -o "<title>[^<]*"   # → «Запах старости:…»
```
Если заголовок другой — файл лёг не туда.

**Про токены:** токен с правами `repo` и `delete_repo` давать нельзя — он позволяет удалить любой репозиторий. Только fine-grained на один репозиторий, срок 7–30 дней, отзывать после работы.

## 17.09.2026 — день, когда сайт чуть не сломался, и что из этого выросло

**Что делали:** закрывали три дыры — мусорный `sitemap (1).xml`, число без источника на четырёх страницах, несходящаяся рецептура цветного порошка.

**Что пошло не так:** заливка через телефон. Файл создался пустым (1 байт), потом папка уехала в корень и главная страница стала страницей карты Осетии. Обе аварии пойманы и откачены за тот же вечер: главная восстановлена из истории побайтово, `/karta-osetii/` возвращена.

**Что это дало хорошего:**
- рецепт цветного порошка пересчитан — было **85,4 %** вместо 100 %, варить по нему было нельзя;
- найдены и убраны ложные упоминания Letocosmetics на двух страницах;
- на четырёх страницах округлённое число заменено измеренным, со ссылкой на DOI;
- заливка переведена на API — руками в подпапку больше никто не кладёт;
- проверены живьём **все 26 URL** из `sitemap-full.xml`: каждый отвечает 200 и содержит текст.

**Главный урок:** расхождение между архивом и сайтом не видно, пока не сверить содержимое. Две правки 15.09 разошлись по разным местам и каждая по отдельности была неполной.
