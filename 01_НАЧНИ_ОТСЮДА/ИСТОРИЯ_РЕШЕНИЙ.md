# Решение 1. Стартовать порошком, а не мылом

**Когда:** при составлении сметы.

**Логика:** мыл на маркетплейсах десятки тысяч — новый бренд утонет в выдаче. Порошок против запаха — пустая ниша. Плюс порошок это расходник: кончается, покупают снова. Мыло тоже расходник, но конкуренция несопоставима.

**Следствие:** первый SKU — порошок для цветного белья. Бюджет 350–450 тыс ₽.

# Решение 8. Измеренное число вместо округлённого

**Когда:** 17 сентября.

**Что было:** на четырёх страницах стояло «полиэстер держит жирные альдегиды в 2-3 раза сильнее хлопка», а источником значилось «cir.nii» — голый текст ссылки.

**Разбор:** ссылка вела на настоящую статью (Munk et al. 2000, *J Surfact Deterg*), но **числа «в 2-3 раза» в ней нет**. Она подтверждает только направление: из хлопка запах вымывается, на полиэстере держится.

**Решение:** вместо округлённого числа поставить измеренное и закрыть его ссылкой на DOI. Из Abdul-Bari et al. 2020 (*Text Res J*): обычная стирка удаляет **94,2 %** 2-ноненаля из хлопка и только **59,0 %** из полиэстера. Цифру «в 4–8,5 раза больше в headspace» **не использовали** — это лабораторный замер, его легко оспорить, а наша же красная линия запрещает цифры без первоисточника.

**Побочный эффект:** эти 94/59 работают на продукт лучше, чем «в 2-3 раза», — они прямо объясняют, зачем стирать при 60 °C.

# Решение 10. Заливка на сайт — через API, не через телефон

**Когда:** 17 сентября, после двух аварий подряд.

**Что случилось:**
1. Телефонное приложение GitHub **не сохраняет папку**: тащишь папку `karta-osetii`, а оно вынимает `index.html` и кладёт в текущее место. Так главная страница сайта была перезаписана страницей карты Осетии.
2. До этого файл создался пустым — 1 байт, один перевод строки. Страница отдавала 200 и пустоту, что для поиска хуже, чем 404.

**Решение:** заливку делает ассистент через GitHub API по fine-grained токену (Contents: Read and write только на `zapahstarosti`) — один атомарный коммит, сразу с проверкой. Вручную — только с компьютера, по ссылке `…/upload/main/<папка>`, где путь задан в адресе.

**Обязательная проверка после любой заливки:**
```bash
curl -s https://zapahstarosti.ru/ | grep -o "<title>[^<]*"   # → «Запах старости:…»
```
Если заголовок другой — файл лёг не туда.

**Про токены:** токен с правами `repo` и `delete_repo` давать нельзя — он позволяет удалить любой репозиторий. Только fine-grained на один репозиторий, срок 7–30 дней, отзывать после работы.
