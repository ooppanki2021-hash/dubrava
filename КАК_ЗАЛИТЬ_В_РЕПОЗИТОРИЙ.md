# Как залить этот пакет отдельным репозиторием

## Шаг 1. Создать пустой репозиторий
GitHub → New repository → имя, например `dubrava-project` → **Public** (чтобы ассистент мог читать по ссылке) → Create. Ничего не добавлять (ни README, ни .gitignore).

## Шаг 2. Залить
Распакуйте архив. Внутри папка `ПАКЕТ`. Её содержимое (а не саму папку) заливаем в репозиторий.

**Вариант A — через браузер (без установки чего-либо):**
1. На странице пустого репозитория → `uploading an existing file`.
2. Перетащите туда все папки `01_...`–`06_...` и `README.md` сразу.
3. Commit changes.
> Ограничение GitHub UI: не более 100 файлов за раз. Если ругается — заливайте по папкам, каждая отдельным коммитом.

**Вариант B — через командную строку:**
```bash
cd путь/к/распакованной/ПАКЕТ
git init
git add .
git commit -m "Полный пакет проекта ДУБРАВА"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/dubrava-project.git
git push -u origin main
```

## Шаг 3. Что сказать новому ассистенту
Скопируйте ему это сообщение:

> Вот репозиторий с полным контекстом проекта: https://github.com/ВАШ_ЛОГИН/dubrava-project
>
> Начни с файла `01_НАЧНИ_ОТСЮДА/ПРОЧТИ_ПЕРВЫМ.md`, затем прочитай `ПОЛНОЕ_ДОСЬЕ.md`, `ЗАПРЕТЫ_И_ГРАНИЦЫ.md` и `ИСТОРИЯ_РЕШЕНИЙ.md` — там всё, что нужно знать, чтобы не переспрашивать.
>
> Рабочий сайт живёт в другом репозитории: `ooppanki2021-hash/zapahstarosti` (GitHub Pages, домен zapahstarosti.ru). В этом пакете лежит его полный слепок в `03_сайт/сайт_текущий/` — правки готовь по нему, я залью в боевой репозиторий сам.
>
> Следующая задача: переписать страницу `/poroshok-dlya-tekstila/` по чек-листу AUDIO (`02_документы_проекта/AUDIO_чеклист.md`) как эталон. Фактура — в `ПОЛНОЕ_ДОСЬЕ.md`.

## Важное предупреждение
В пакете есть код входа в приложение (`0820`) и рабочие тексты упаковки. Если репозиторий публичный — это будет видно всем. Если это критично, сделайте репозиторий **приватным** и добавьте ассистента как коллаборатора, либо удалите `05_приложение/` перед заливкой.
