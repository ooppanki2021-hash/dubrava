# АУДИТ БЕЗОПАСНОСТИ И ДОСТОВЕРНОСТИ КОНТЕНТА — zapahstarosti.ru

**Дата:** 24.09.2026 · **Объект:** живой сайт, коммит `2a87bd7`, 25 страниц + результаты квиза (JS), ~23 300 слов
**Метод:** полный текст каждой страницы → автоматический отбор фраз с дозами, температурами, химией, медицинскими терминами и обещаниями (576 фраз) → ручной разбор.
**Тема сайта — здоровье (YMYL).** Яндекс и Google оценивают такие тексты строже всего; опасные советы и недоказанные медицинские/продуктовые утверждения — прямые признаки низкого качества. Вероятно, одна из причин статуса LOW_QUALITY в Вебмастере.

Уровни: **P0** — может причинить вред, исправить первым; **P1** — серьёзный медицинский, химический или юридический риск; **P2** — неточности и недоказанные цифры, подрывают доверие.

Этот документ восстанавливает потерянный ранее аудит (сохранились только формулировки: «P0 по опасному квизу останется, пока опасные действия доступны; P1 по медицинским выводам — пока сохраняется диагностика по запаху; P1 по химии — пока есть универсальные дозы и рецепты; P1 по продуктовым обещаниям — пока гипотезы описаны как эффективность»). **На 24.09.2026 все четыре пункта открыты.** Исправления не вносились — ждут решения автора.
