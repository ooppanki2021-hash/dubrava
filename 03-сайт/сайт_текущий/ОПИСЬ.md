## сайт_текущий/ — полный слепок на 15.09.2026

- 26 папок страниц, в каждой `index.html`
- `index.html` в корне — главная
- `style.css` — все стили
- `sitemap.xml` (6 URL), `sitemap-full.xml` (26 URL), `sitemap-week1.xml`
- `robots.txt`
- `CNAME` — **не трогать**, привязка домена
- `yandex_e3e7231de3258122.html`, `googlebfe090009deb22b8.html` — верификация, **не удалять**
- `images/` — 26 картинок, ~3 МБ
- `constructor-v5.html` — конструктор страниц, вход `?admin=1`

**Как редактировать:** править файлы здесь, отдавать Инне архивом с сохранением структуры папок. Она заливает через GitHub → Add file → Upload files.
