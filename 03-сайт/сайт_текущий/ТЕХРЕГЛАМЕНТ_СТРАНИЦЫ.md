## 1. Обязательный каркас `<head>`

Порядок блоков строго такой (по нему работает конструктор — он ищет маркеры-комментарии):

```html
<!DOCTYPE html>
<html lang="ru"><head>
<meta charset="utf-8">
<meta name="yandex-verification" content="e3e7231de3258122">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>…</title>
<meta name="description" content="…">
<link rel="canonical" href="https://zapahstarosti.ru/СЛАГ/">
<link rel="stylesheet" href="/style.css?v=6">
<!--OG-START-->  … 9 тегов og/twitter …  <!--OG-END-->
<!--JSONLD-START--> … ld+json Article … <!--JSONLD-END-->
<!-- Yandex.Metrika counter --> … id=111871686 … <!-- /Yandex.Metrika counter -->
</head>
```

**Нельзя трогать:**
- `yandex-verification content="e3e7231de3258122"` (и `89b93e0a5051b627` там, где стоит https-вариант) — подтверждение прав в Вебмастере;
- счётчик Метрики `111871686`;
- маркеры `<!--OG-START-->`, `<!--OG-END-->`, `<!--JSONLD-START-->`, `<!--JSONLD-END-->` — по ним конструктор перезаписывает блоки. Удалите — конструктор сломается на этой странице.

## 2. Правила заполнения метаданных

| Поле | Правило |
|---|---|
| `title` | **50–65 символов.** Сейчас на 14 страницах до 82 — обрезается в выдаче, это открытый долг. Формула: `Главный запрос: уточнение через двоеточие` |
| `description` | 140–165 символов. Не повтор title. Перечисление того, что реально есть в статье, без «узнайте» и «в нашей статье» |
| `canonical` | Абсолютный URL со слэшем на конце. Всегда свой собственный |
| `og:title` / `og:description` | Дублируют title/description один-в-один |
| `og:image` | `https://zapahstarosti.ru/images/og/СЛАГ.jpg`, 1200×630. **Если картинки нет — её надо создать, иначе шеринг битый** |
| `ld+json` `headline` / `description` / `url` / `image` | Дублируют то же самое |
| `dateModified` | Обновлять при каждой правке текста. Формат `2026-09-15` |
| `author` | Всегда Инна Кучиева, url `/o-proekte/` |

## 3. Каркас `<body>`

```html
<body>
<header class="header"> … общее меню … </header>
<script> … показ пункта «Конструктор» по ?admin=1 … </script>
<main class="container"><div class="content" style="padding-top:48px">
<div class="article-body">
  <h1>…</h1>
  <p>лид-абзац</p>
  <h2>…</h2>
  …
</div>
</div></main>
<footer class="footer"> … </footer>
</body>
```

- **Меню одинаковое на всех страницах.** Пять выпадающих групп: Диагностика, 2-ноненаль, Тело, Квартира, Средства, О проекте. Менять пункт меню — значит менять его во всех 27 файлах разом. Делать скриптом, не руками.
- `<h1>` ровно один, внутри `.article-body`, первым элементом.
- Дальше только `h2`. `h3` в текущей вёрстке не стилизован — не использовать.
- Пункт «Конструктор» со `style="display:none"` и его скрипт — оставлять, это админский вход.

## 4. CSS: что можно применять

Файл `/style.css` (7,4 КБ). Доступные классы:

| Класс | Назначение |
|---|---|
| `.article-body` | Обёртка тела статьи. Внутри автоматически стилизуются `h2`, `ul/ol`, `li`, `table`, `th/td` |
| `.lead` | Вводный абзац крупнее |
| `.note` | Серая врезка-примечание |

| `.sage` | Зелёная акцентная врезка |
| `.table-min` / `.table-wrap` | Таблицы. `.table-wrap` даёт горизонтальный скролл на мобильном |
| `.figure` + `figcaption` | Картинка с подписью |
| `.leadmagnet` | Блок с призывом |

⚠️ **Запрет:** не оборачивать тело статьи в `.small` или `.muted` — текст станет 13 px и серым. Это уже случалось.
⚠️ Не вставлять `<font color="...">` — остаток чужой вёрстки, вычищается.
⚠️ Цвет основного текста задан переменной `--text:#2C333A`. Не переопределять инлайном.

## 5. Внутренние ссылки

- Ставить абсолютные: `https://zapahstarosti.ru/слаг/`.
- Проверять полезность и статус ссылок: сейчас открыты 25 из 26 контентных страниц. `noindex` не означает недоступность читателю; ссылка может быть полезной, но не должна обещать отсутствующий товар или готовую инструкцию. Массовый запрет на все такие ссылки не подменяет редакционное решение.
- Каждая статья ссылается минимум на: свой хаб + 2 смежные статьи.
- Три хаба: `/zapah-v-kvartire/`, `/sredstva-ot-zapaha/`, `/ubrat-zapah/`. **Хаб ≠ статья:** хаб — это навигационный список с короткими аннотациями (`.list-plain`), статья — глубокий разбор. Не превращать хаб в лонгрид.
- Открытый долг: `/sredstva-ot-zapaha/` и `/ubrat-zapah/` пересекаются по смыслу — их надо развести.

## 6. Стандарт качества текста — AUDIO

Страница не публикуется (не снимается `noindex`), пока не закрыты **все пять** пунктов. Подробно — в `02_документы_проекта/AUDIO_чеклист.md`.

| Буква | Что требуется |
|---|---|
| **A** — Authority | Ссылки на PubMed/PMC с номерами, названные исследователи, годы. Не «учёные доказали» |
| **U** — Uniqueness | Свой опыт, свои измерения, свои формулировки. Не пересказ трёх статей из выдачи |
| **D** — Depth | Механизм «почему», а не только «что делать». Разбор народных методов с объяснением, почему не работает |
| **I** — Intent | Ответ на реальный вопрос человека в первых двух абзацах |
| **O** — Optimization | title/description/og/ld+json/перелинковка по этому регламенту |

**Прямой запрет автора:** не открывать страницу в поиск, пока на ней «очень поверхностная банальщина».

**Шаблонный хвост** («Проверка результата» / «Что делать, если не помогло» / «Профилактика») — **не удалять**, а переписывать уникально под каждую страницу.

**Запрещённые формулировки** (юридический риск): «у 2/3 людей 40+», «n=22», «лечит», «убивает», «100 %», «навсегда», «дуб лучше хурмы». Слово «старость» — только как SEO-запрос, в тексте о человеке так не писать.
