## Как отдавать результат

Инна заливает файлы сама через веб-интерфейс GitHub. **Готовь архив с сохранением структуры папок**, чтобы можно было перетащить целиком.

⚠️ **Телефонное приложение GitHub класть файл в подпапку не умеет** — вынимает `index.html` из папки и кладёт в корень. Так 17.09 была перезаписана главная страница. Надёжно: **GitHub API по fine-grained токену** (один атомарный коммит) либо с компьютера по ссылке `…/upload/main/<папка>`. После заливки проверить: `curl -s https://zapahstarosti.ru/ | grep -o "<title>[^<]*"` — должен остаться «Запах старости:…».
